# Интернет‑магазин (Django + PostgreSQL + Celery + Redis + Nginx)

Мини‑проект для управления товарами, производителями и заказами.  
Включает CRUD‑API, загрузку CSV, фоновую обработку задач и reverse‑proxy через Nginx.

---

## 🚀 Запуск проекта

### Требования
- Docker  
- Docker Compose  

### Команда запуска

```bash
docker-compose up --build
